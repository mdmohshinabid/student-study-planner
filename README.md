# 📚 Student Study Planner

A responsive and user-friendly web application designed to help students organize their study tasks, manage deadlines, and track their study progress.

🌐 **Live Demo:** https://mdabidchy.github.io/student-study-planner/

## ✨ Features

- Add and manage study tasks
- Set subject, due date, and priority
- Mark tasks as completed or pending
- Delete tasks
- Filter tasks by status
- Search tasks by title
- View total, completed, and pending tasks
- Track study progress with a progress bar
- Weekly and monthly calendar views
- Navigate between calendar dates
- Dark Mode and Light Mode
- Customize the accent color
- Export and import tasks using JSON files
- Save tasks automatically using browser Local Storage
- Responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- JSON

## 🚀 How to Use

1. Open the live website using the link above.
2. Enter a task title.
3. Select a subject, due date, and priority.
4. Click the Add Task button.
5. Manage your tasks using the available options.
6. Track your progress through the dashboard and calendar.

## 💻 How to Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start organizing your study tasks.
