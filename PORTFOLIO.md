## 1. About the Project

Student Study Planner is a responsive web application designed to help students organize their academic activities and manage their study schedules.

The application allows students to create tasks, set deadlines, choose priorities, track their progress, and manage their study plans through weekly and monthly calendar views.

I developed this project to improve my practical programming skills and understand how HTML, CSS, and JavaScript work together to create an interactive web application.

## 3. Key Features

- Create and manage study tasks.
- Set subjects, due dates, and priorities.
- Mark tasks as completed or pending.
- Delete unwanted tasks.
- Search tasks by title.
- Filter tasks by completion status.
- View total, completed, and pending tasks.
- Track study progress with a progress bar.
- Switch between weekly and monthly calendar views.
- Use Light Mode and Dark Mode.
- Customize the accent color.
- Import and export task data using JSON files.
- Save tasks using browser Local Storage.
- Responsive layout for smaller screens.
