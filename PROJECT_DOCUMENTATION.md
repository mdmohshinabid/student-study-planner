## 1. Project Overview

Student Study Planner is a simple and responsive web application designed to help students organize their academic tasks and manage their study schedules.

Students can add tasks, set deadlines, choose priorities, track completed work, and monitor their study progress. The application also provides weekly and monthly calendar views to make study planning easier.

This project was developed as a practical way to learn and apply front-end web development skills using HTML, CSS, and JavaScript.

## 2. Project Objectives

The main objectives of this project are:

## 5. How the Application Works

The application uses HTML to create the structure of the website and CSS to design its appearance.

JavaScript manages the application's main functionality. When a user adds a task, JavaScript collects the information and updates the task list.

The dashboard calculates the total, completed, and pending tasks. It also displays the completion percentage through a progress bar.

The calendar organizes tasks according to their due dates. Users can switch between weekly and monthly views.

The application uses browser Local Storage to keep task information available after the browser is closed or the page is refreshed.

## 6. Data Storage

The application uses the browser's Local Storage to save study tasks.

Local Storage allows the application to store information in the user's browser without requiring a separate database or server.

The task information is saved under the `studyTasks` key.

This means users can normally access their saved tasks again when they reopen the website in the same browser.

**Important:** Local Storage is browser-specific. Clearing browser data or using another browser or device may make previously saved tasks unavailable. Users can use the JSON export feature to keep a backup.

## 9. Current Limitations

Some limitations of the current version include:

- Task information is stored locally in the browser.
- There is no user account or login system.
- Data is not automatically synchronized between devices.
- There is no cloud database or online backup system.
